# 指對數實驗室｜單元 5～7 總複習

高中數學「單元 5 指數函數、單元 6 對數與對數律、單元 7 對數函數」的課堂複習遊戲。
大螢幕分成左、中、右三區，三位同學同時上台、各玩各的；一位玩完就能立刻換下一位。

- 純前端靜態網頁，**不需要安裝、不需要編譯**，放上 GitHub Pages 就能用。
- 也可以直接在電腦上雙擊 `index.html` 開啟（教室網路斷線時的備案）。
- 支援 Chrome、Edge。

---

## 一、放上 GitHub Pages

### 方法 A：用網頁上傳（最簡單）

1. 在 GitHub 建立新的 repository，例如 `log-lab`，設為 **Public**。
2. 進入 repository → **Add file → Upload files**。
3. 把解壓縮後 `log-lab` 資料夾「裡面」的所有檔案與資料夾拖進去（`index.html` 要在最上層，不要多包一層資料夾）。
   - 共約 50 個檔案，一次就能上傳完（GitHub 網頁一次上限 100 個）。
   - 資料夾裡有一個隱藏檔 `.nojekyll`，如果檔案總管沒顯示也沒關係，少了它網站一樣能運作。
4. 按 **Commit changes**。
5. 到 **Settings → Pages**：
   - Source 選 **Deploy from a branch**
   - Branch 選 **main**、資料夾選 **/ (root)**，按 **Save**。
6. 約 1 分鐘後，網址會是：`https://你的帳號.github.io/log-lab/`

### 方法 B：用 git

```bash
cd log-lab
git init
git add .
git commit -m "指對數實驗室"
git branch -M main
git remote add origin https://github.com/你的帳號/log-lab.git
git push -u origin main
```

之後一樣到 **Settings → Pages** 開啟（同上第 5 步）。

## 二、教室設定（Surface Pro 8 ＋ ViewSonic IFP8653）

### 1. 連線：上課請用 USB-C 線

- 用全功能 USB-C 線連接時，畫面與**觸控**都會走同一條線，三人同時觸控最穩定。
- AirSync 無線投影通常只傳畫面，觸控可能無法回傳到筆電，延遲也較高，建議只作備用。

### 2. 先做一次「觸控測試」

1. 開啟遊戲 → **長按右上角「⚙ 設定」2 秒** → 按「開始觸控測試」。
2. 請三位同學同時在左、中、右區拖曳手指，畫面上應該同時出現三個圓圈，右上角「最多同時」要到 3。
3. 如果觸控位置跟手指對不上（例如點大螢幕卻點到筆電螢幕的位置）：
   Windows「控制台 → 平板電腦設定 → 設定…」→ 依照提示在大螢幕上點一下，讓 Windows 知道觸控是屬於哪個螢幕。

### 3. 建議關閉 Windows 的多指手勢

學生多指同時操作時，Windows 可能誤判成三指／四指手勢而切換視窗：

- Windows 11：**設定 → 藍牙與裝置 → 觸控 → 關閉「三指和四指觸控手勢」**
- （進階、選用）從螢幕邊緣滑入叫出小工具／通知中心：可用群組原則
  「電腦設定 → 系統管理範本 → Windows 元件 → 邊緣 UI → 允許邊緣撥動」設為「已停用」。
  Windows 家用版沒有群組原則編輯器，可略過此項。

### 4. 用「Kiosk 模式」開啟（最能防止學生亂點）

Kiosk 模式沒有網址列、分頁和瀏覽器選單，學生點不出任何瀏覽器功能。在桌面建立捷徑，「目標」填入下列其中一行（網址換成你的）：

**Chrome**

```
"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --user-data-dir="C:\LogLabKiosk" https://你的帳號.github.io/log-lab/
```

**Edge**

```
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --kiosk https://你的帳號.github.io/log-lab/ --edge-kiosk-type=fullscreen --no-first-run
```

- 離開 Kiosk 模式：按鍵盤 **Alt＋F4**。
- Chrome 的 `--user-data-dir` 會另開一個獨立的瀏覽器設定檔，這樣即使 Chrome 已經開著也能進入 Kiosk 模式。
- Edge 若已經開著，Kiosk 參數會被忽略：請先關掉所有 Edge 視窗；必要時到 `edge://settings/system` 關閉「啟動提升」。
- 遊戲設定存在「瀏覽器設定檔」裡，Kiosk 視窗用的是獨立設定檔，所以**請在 Kiosk 視窗裡調整設定**。

不使用 Kiosk 時，也可以按畫面右上角「⛶ 全螢幕」。全螢幕時要**長按 1.5 秒**才會離開，避免學生誤觸。

## 三、上課怎麼玩

1. 三位同學各站一區，按「開始挑戰」。
2. 每人玩 6 關（每個單元 2 關），每關一道挑戰題，時間顯示在各區上方。
3. 玩完會顯示總分與每關結果，下方「再玩一次」約 3 秒後亮起，下一位同學按它就直接開始。
4. 同學中途離開：教師到設定頁「重新開始」把該區回到開始畫面。

### 計分規則

| 情況 | 結果 |
|---|---|
| 答對 | 15 分＋剩餘秒數（剩餘秒數會化成光點飛進分數） |
| 主動按「求救卡」 | 出現提示，扣 10 秒（每關一張） |
| 第一次答錯 | 自動用掉求救卡：出現提示、扣 10 秒，可以再答 |
| 再次答錯，或時間到 | 本關 0 分，顯示正解，5 秒後自動進入下一關（也可按「下一關」） |
| 剩 10 秒以內 | 求救卡變灰；此時答錯直接結束本關 |

- 轉場、慶祝與展示正解的時間不計入作答秒數。
- 開啟設定頁時，三區全部暫停。

### 六個關卡

| 關卡 | 單元 | 玩法 | 複習內容 |
|---|---|---|---|
| 1 細菌培養皿 | 5 | 拖動底數滑桿，按「培養！」讓曲線長到目標點 | 指數函數圖形、過 (0,1)、對稱於 y 軸 |
| 2 拆彈小組 | 5 | 用手指劃過電線，剪斷正確答案 | 指數方程式、指數不等式、半衰期 |
| 3 電路接線 | 6 | 把算式拖線接到它的值 | 對數定義、對數律、換底公式 |
| 4 巨數望遠鏡 | 6 | 轉動數字轉盤輸入答案 | 常用對數、科學記號、位數、海嘯／星等／分貝 |
| 5 鏡像傳送門 | 7 | 選出曲線穿過傳送門（鏡射）後的樣子 | 對數函數圖形、對稱於 y=x、x 軸、y 軸 |
| 6 骨牌魔王關 | 7 | 選答案推倒 3D 骨牌，超越臺北 101 | 對數方程式、對數不等式、骨牌問題 |

- 題目數字都設計成**可以心算**；需要的對數值（log 2、log 3）會直接寫在題目上。
- 每關從題庫隨機出題，並避開三區最近出過的題目，後面的同學看前面的人玩也抄不到答案。

## 四、教師設定（長按「⚙ 設定」2 秒）

| 類別 | 項目 | 預設 |
|---|---|---|
| 遊戲 | 每關秒數 30～60（每 5 秒一級） | 45 |
| | 難度：簡單／標準／挑戰 | 標準 |
| | 求救卡扣秒：5／10／15 | 10 |
| | 答對基本分：10／15／20 | 15 |
| | 啟用關卡（可只複習部分單元） | 全部 |
| 觸控與顯示 | 拖曳啟動距離：短／中／長 | 中 |
| | 點擊容錯範圍：小／中／大 | 中 |
| | 手掌誤觸過濾：關閉／標準／嚴格 | 標準 |
| | 畫面解析度：100%／75%／50%（動畫卡頓時調低） | 100% |
| | 特效：完整／精簡 | 完整 |
| | 音效：關／小／中／大 | 中 |
| 課堂管理 | 時間預估（可調全班人數） | 27 人 |
| | 重新開始：左區／中區／右區／全部 | |
| | 設定頁密碼（4 位數，選用） | 未設定 |

- 設定自動存在這台電腦的瀏覽器裡，下次開啟會保留。
- 遊戲參數（秒數、難度等）從**每一區的下一位同學**開始生效，不會影響正在玩的同學。
- 時間預估：每關 45 秒時，每位同學最長約 5 分 08 秒，每區 9 人最長約 49 分鐘（含轉場、解答展示與換人）。「最長」是每關都用完時間的情況，多數同學會提早完成；如果班上作答較慢，可以調成 40 秒。

## 五、修改題目

每一關的題庫都在 `js/levels/` 裡對應的檔案，分成 `easy`、`normal`、`hard` 三組：

| 檔案 | 題庫格式 |
|---|---|
| `l1-bacteria.js` | `P(底數位置, x 分子, x 分母, y)`：目標點 (x, y)；`M(位置)`：對稱於 y 軸 |
| `l2-bomb.js`、`l6-domino.js` | `Q(代號, 題目, [正解, 干擾1, 干擾2, 干擾3], 提示, 解說, 驗算)`，**選項第一個是正解**，畫面上會自動打亂 |
| `l3-circuit.js` | `E(算式, 值, 類型, 驗算)` |
| `l4-telescope.js` | `D(底數, 次方)` 求位數、`F(底數, 次方)` 求小數點後第幾位 |
| `l5-mirror.js` | `Q(代號, 原曲線, [鏡射方式], [正解曲線, 干擾, 干擾])` |

數學式用 `$...$` 包起來，寫法與 LaTeX 相同（例如 `$\log_{2}8$`、`$\dfrac{3}{2}$`）。
注意：JavaScript 字串裡的反斜線要寫兩個，例如 `'$\\log_{2}8$'`。

## 七、疑難排解

| 狀況 | 處理方式 |
|---|---|
| 觸控沒反應或點不準 | 確認使用 USB-C 線；用設定頁的「觸控測試」檢查；必要時做「平板電腦設定」的觸控對應 |
| 三人同時操作時卡頓 | 設定頁把「畫面解析度」調成 75% 或 50%，「特效」改成精簡 |
| 學生不小心點到別區 | 每根手指只會作用在按下時的那一區，手指滑到隔壁區也不會影響別人 |
| 手掌碰到螢幕造成誤觸 | 「手掌誤觸過濾」改成嚴格 |
| 第 6 關沒有 3D 畫面 | 電腦不支援 WebGL 時會自動改用 2D 骨牌動畫，遊戲照常進行 |
| 網路斷線 | 直接雙擊電腦上的 `index.html` 開啟（設定需在該視窗重新調整） |
